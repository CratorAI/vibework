# Contributing

Start with the README build instructions and DESIGN.md. Keep changes focused,
include reproduction steps for bugs and describe tests performed in the PR.
Run TypeScript, Vitest, Cargo tests and a warnings-denied Cargo build before
submitting. Never commit credentials, personal recordings or local machine paths.
Use synthetic fixtures and preserve third-party notices.

The owner must select a project licence before accepting public contributions.
Do not change release signing settings or run release workflows for routine tests.
Use an isolated app data directory for development automation; never drive an
installed app or a person's live accounts in tests. Treat other contributors
respectfully and discuss the work rather than the person.
