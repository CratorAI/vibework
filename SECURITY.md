# Security

Report vulnerabilities privately using GitHub's **Security → Report a vulnerability**
for [this repository](https://github.com/CratorAI/vibework/security/advisories/new).
The owner must enable private vulnerability reporting before public launch.
Do not open a public issue containing exploitation details, keys, logs or personal data.
Include the app version, platform, impact and a minimal reproduction with synthetic data.
Only the latest release is intended to receive security fixes; no response-time guarantee
is currently offered. Agents can run commands and change files: use permission prompts
and limit workspace access to what a task needs.
